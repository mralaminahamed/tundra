## What Tundra manages

<CardGrid>
  <Card title="Multi-runtime sites" icon="rocket">
    PHP, Node.js, Python, Go, Rust, Ruby, .NET. Atomic symlink release swap with the 5 newest releases kept (slot start and health checks are stubs; no rollback operation yet), 13 starter templates.
  </Card>
  <Card title="WordPress" icon="puzzle">
    WP-CLI lifecycle, per-install DB isolation, plugin/theme management, staging and cloning.
  </Card>
  <Card title="Multi-server fleet" icon="laptop">
    SSH agent install over HTTPS-polling agents (mTLS gRPC is planned), cross-server site move (pipeline is a stub), maintenance windows.
  </Card>
  <Card title="Databases" icon="setting">
    PostgreSQL, MySQL, MariaDB, Valkey — CRUD, access control, connection strings.
  </Card>
  <Card title="DNS & Mail" icon="email">
    PowerDNS zones, 30 provider-ready DNS templates, Postfix + Dovecot + Rspamd + DKIM.
  </Card>
  <Card title="Backups" icon="document">
    restic + GPG encryption. S3, B2, R2, Wasabi, SFTP, or local. Preview-then-confirm restore.
  </Card>
  <Card title="Plugin system" icon="open-book">
    Wasmtime plugin host library with WIT SDK, capability gate and resource limits (not yet wired into `tundrad`). Bundled plugin crates: WordPress, GitHub, Namecheap, MCP.
  </Card>
  <Card title="MCP AI integration" icon="star">
    Connect Claude Code, Claude Desktop, Cursor, Zed. Manage infrastructure from your AI editor.
  </Card>
</CardGrid>
